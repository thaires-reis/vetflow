**VetFlow**

## Problema que o sistema pretende resolver

Clínicas veterinárias precisam gerenciar informações relacionadas aos tutores, animais, profissionais, agendamentos e atendimentos.

Quando esses dados não estão centralizados e organizados, podem ocorrer dificuldades na localização de informações, no acompanhamento do histórico dos animais e na gestão da agenda dos profissionais.

O sistema propõe centralizar essas informações em uma única aplicação, permitindo o gerenciamento dos pacientes, tutores, profissionais, consultas e atendimentos, com mecanismos de pesquisa, filtros, controle de acesso e proteção das informações de acordo com o perfil do usuário.

## Primeiras entidades

| Entidade | Função |
|---|---|
| `usuarios` | Usuários que acessam o sistema |
| `tutores` | Responsáveis pelos animais |
| `animais` | Pacientes da clínica |
| `veterinarios` | Profissionais veterinários |
| `especialidades` | Especialidades dos veterinários |
| `consultas` | Agendamentos e consultas dos animais |
| `atendimentos` | Registro dos atendimentos realizados |
