🐾 VetFlow

Sistema de gestão para clínicas veterinárias

Projeto Integrador da disciplina de Laboratório de Banco de Dados — FATEC Americana.

# Sobre o projeto

O VetFlow é uma proposta de sistema para auxiliar na gestão de clínicas veterinárias, centralizando informações sobre tutores, animais, profissionais, consultas e atendimentos em uma única aplicação.

O projeto está em fase inicial de desenvolvimento e tem como objetivo aplicar os conceitos de modelagem, implementação e manipulação de bancos de dados relacionais, integrando-os a uma aplicação funcional.

# Problema e solução

Clínicas veterinárias precisam gerenciar informações relacionadas aos tutores, animais, profissionais, agendamentos e atendimentos.

Quando esses dados não estão centralizados e organizados, podem ocorrer dificuldades na localização de informações, no acompanhamento do histórico dos animais e na gestão da agenda dos profissionais.

O VetFlow propõe centralizar essas informações em uma aplicação que permita organizar os cadastros, consultar agendamentos, pesquisar pacientes e profissionais e acessar o histórico de atendimentos, com controle de acesso e proteção das informações.

# Funcionalidades previstas

Cadastro e consulta de tutores e animais.
Cadastro e consulta de veterinários e especialidades.
Agendamento e gerenciamento de consultas.
Pesquisa e filtros por paciente, profissional, data e horário.
Registro e consulta do histórico de atendimentos.
Autenticação de usuários e controle de acesso.

As funcionalidades serão implementadas progressivamente durante o desenvolvimento do projeto.

 #Modelagem inicial do banco de dados

As entidades inicialmente planejadas são:

usuarios- Gerenciar os usuários que acessam o sistema.
tutores- Armazenar os dados dos responsáveis pelos animais.
animais- Armazenar os dados dos pacientes da clínica.
veterinarios- Registrar os profissionais veterinários.
especialidades- Organizar as especialidades veterinárias.
consultas- Gerenciar os agendamentos e as consultas.
atendimentos- Registrar as informações dos atendimentos realizados.

A modelagem poderá incluir tabelas complementares conforme a definição dos relacionamentos e das regras de negócio.

# Tecnologias

As tecnologias serão definidas durante o planejamento do projeto, considerando os requisitos da disciplina e a integração entre a aplicação e o banco de dados relacional.
